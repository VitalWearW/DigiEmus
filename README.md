# 🇬🇧 ENGLISH

## 🎮 About DigiEmu

DigiEmu is a collection of Android emulators dedicated to different generations of Digital Monster virtual pet devices.

Enjoy your favourite devices, explore different versions and experience Digital Monster emulation directly on Android.

## 🕹️ Available Emulators

| Emulator | Device |
|---|---|
| **DigiEmu-DMC** | Digital Monster Color |
| **DigiEmu-D3-25TH** | Digimon D3 25th Anniversary |
| **DigiEmu-D-Ark** | D-Ark |
| **DigiEmu-DigiVice-Color** | Digivice Color |
| **DigiEmu-PenC** | Pendulum Color |
| **DigiEmu-DMX** | Digital Monster X — Alpha remake |
| **DigiEmu-DM20TH** | Digital Monster Ver.20th — Alpha remake |
| **DigiEmu-DMClassic** | Digital Monster Classic |

## 📥 Download & Installation

1. Open the **Releases** section of this GitHub repository.
2. Choose the emulator you want.
3. Download its APK.
4. Install it on your Android device.
5. Open the emulator and enjoy!

If App and Widget editions are available, choose the one you prefer.

## 💾 ROM Requirements

Some emulators require compatible ROM dumps from your own devices.

| Emulator | ROM requirements |
|---|---|
| DMC | Compatible ROM dump |
| DM Classic | Compatible ROM dump |
| Other original-device emulators | Dump from your own compatible device |
| DM20th | Alpha remake |
| DMX | Alpha remake |

### ROM references

For compatibility reference, you can search online for:

- **DMC:** `digicolr.zip` (MAME).
- **DM Classic:** `digimon.zip` (MAME).

DM Classic can also use compatible custom ROM files.

For other original-device emulators, you will need the appropriate dump for the device you want to emulate.

Only use ROM files you are legally entitled to use.

## 🧪 DM20th & DMX — Alpha Remakes

⚠️ **DM20th and DMX are currently Alpha remakes.**

These are experimental recreations and are still under development.

Features, compatibility and behaviour may change between releases.

## 🔗 Communication Features

### 🔵 DCom — Offline Communication

DCom allows direct offline communication with a compatible emulator.

**How to use:**

1. Open the emulator.
2. Access the DCom option.
3. Select the compatible emulator or destination.
4. Follow the instructions displayed on screen.
5. Complete the communication process.

No online chat session is required.

### 🌐 IRCCom — Online Communication

IRCCom is an online communication system that allows users to chat with each other.

**How to use:**

1. Open IRCCom.
2. Enter your preferred **nickname (nick)**.
3. Complete the connection and room-selection steps shown in the app.
4. Join the conversation.
5. Start chatting with other users!

Your nickname is the name other users will see. Choose your own nickname and enjoy the community.

An Internet connection is required.

## 🔗 Funciones de comunicación

### 🔵 DCom — Comunicación Offline

DCom permite la comunicación directa sin conexión con un emulador compatible.

**Cómo utilizarlo:**

1. Abre el emulador.
2. Accede a la opción DCom.
3. Selecciona el emulador o destino compatible.
4. Sigue las instrucciones que aparecen en pantalla.
5. Completa el proceso de comunicación.

No necesita una sesión de chat online.

### 🌐 IRCCom — Comunicación Online

IRCCom es un sistema de comunicación online que permite conversar con otros usuarios.

**Cómo utilizarlo:**

1. Abre IRCCom.
2. Introduce el **nick (apodo)** que quieras utilizar.
3. Completa los pasos de conexión y selección de sala que aparecen en la aplicación.
4. Entra en la conversación.
5. ¡Empieza a hablar con otros usuarios!

Tu nick será el nombre que verán los demás. Elige el que quieras y disfruta de la comunidad.

Necesitas conexión a Internet.
